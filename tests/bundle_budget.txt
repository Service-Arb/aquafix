# Maximum gzip bytes of first-load JavaScript on a point page
# (`/[locale]/[location]`), checked by `nix run .#size` (scripts/bundle-budget.ts).
#
# The visitor this page is designed for is on mobile data in the middle of an
# emergency, so this is the one number worth gating. The quote form posts
# without any of it — the budget is for what the page costs to become
# interactive, not for whether it works.
#
# Measured: 152,847 B gz (498.5 KB raw), Next 16.3.6 / Turbopack, uikit 0.20.0,
# marketing 0.3.0 — down from 214,988 on uikit 0.19.0 / marketing 0.2.0, once
# the kit shipped one module per file (a server-rendered `Button` no longer
# brings the kit's client half) and the contact tracker stopped pulling motion.
# Ceiling set ~4.5% above so ordinary churn does not trip it and a real
# regression does. By chunk, identified by what each one contains:
#   ~71.6 KB  react-dom
#   ~44.1 KB  the Next app-router runtime
#   ~37 KB    the rest: Turbopack runtime, route chunks, the uikit's client
#             islands, the analytics island and the contact tracker
# For comparison, the Dioxus build this replaces shipped 1,168,203 B of
# uncompressed wasm; the equivalent raw figure here is ~500 KB.
#
# Raising this is a deliberate commit with a reason in the message, never a
# silent edit.
160000
