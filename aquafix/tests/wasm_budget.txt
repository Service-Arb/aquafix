# Maximum bytes for the release `*_bg.wasm`, checked by `nix run .#size`.
#
# The visitor this page is designed for is on mobile data in the middle of an
# emergency, so this is the one number worth gating.
#
# Measured: 1,043,157 B. Ceiling set ~5% above so ordinary churn does not trip
# it and a real regression does. Reference points on the way here:
#   1,059,047  with ev_lib::analytics (reqwest transport)
#     833,202  with the same events over navigator.sendBeacon
#     823,287  with analytics removed entirely — i.e. capture now costs ~10 KB
#     833,186  the same tree remeasured through `nix build .#dx`
#   1,043,157  with French
# REA measured the bare dioxus floor (core + web + signals) at ~420 KB; the rest
# here is the router plus SSR hydration.
#
# The French delta is +209,971 B, decomposed by building three variants of the
# same tree through the same pipeline:
#   +104,940  the FR const — a second copy of every string
#    +70,401  the seam: Text, a `lang` prop on 19 sections, the switcher, the
#             hreflang and per-language schema.org plumbing
#    +34,630  the route pairs — each page answers at /x and /:lang/x, and the
#             router macro's codegen is a large share of this bundle
# A third language costs roughly the first term again and nothing else.
#
# Raising this is a deliberate commit with a reason in the message, never a
# silent edit. The levers, in order: move another interaction to native HTML
# (the FAQ and the mobile drawer are already `<details>`), then wasm-opt -Oz,
# then serve the two languages as two bundles rather than one.
