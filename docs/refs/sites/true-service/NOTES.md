# trueserviceplumbing.com — COUNTER-EXAMPLE: minimalism with the answers removed

**Proof on page:** "upfront" ×1, "free estimate" ×1. That is essentially the entire
conversion signal set on the page (grade D — our own reading of the capture).

## Why it is in the set

It is the cleanest site in the folder and the weakest converter in it, and those two facts
are related. Roundups praise the minimalist homepage, clean imagery and well-placed CTAs.
The capture shows what that minimalism costs: no published price, no named warranty term,
no licence number, no arrival commitment, no named people.

## The lesson

**Removing pixels is only a win when the removed pixels were not carrying an objection.**
Ponytail logic applies to code, not to proof. A short page and a dense page are both fine;
a *silent* page is not.

Compare Hyros — also visually restrained, but every retained element is either the offer or
proof of it. Restraint is about what you keep, not how little you keep.

## Effect on the Aquafix design

This site is the direct reason the page is long. It is ~8,460px on desktop and every band
answers a specific question a homeowner asks before letting a stranger into their house:

```
  price?      → published table
  when?       → 2-hour window + penalty
  mess?       → before/after photos
  lasts?      → 12-month warranty
  who?        → four named plumbers, licence numbers
  legit?      → proof bar, CCB #, insurance
  covered?    → service-area list with an explicit refusal boundary
```

Delete any band and a question goes unanswered. Length was never the risk; silence was.
